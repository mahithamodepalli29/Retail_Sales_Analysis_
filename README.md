# Retail Sales Data Analysis

## Objective
Analyse retail sales data to understand sales trends, customer demographics and product performance.

## Tools Used
Python, pandas, matplotlib, seaborn (Google Colab)

## Key Findings
- Electronics and Clothing lead sales, and Beauty trails slightly
- Saturday is the best sales day and Thursday the weakest
- Age alone does not predict spending
